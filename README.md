# pencode extensions

The official extension registry for [pencode](https://github.com/pencode-labs/pencode).

This repository maintains the list of available pencode extensions in [`extensions.json`](./extensions.json).

## Available extensions

| Extension | Description |
| --- | --- |
| [php](https://github.com/pencode-labs/php) | PHP and Blade language support and Xdebug integration for Pencode |
| [codex](https://github.com/pencode-labs/codex) | Codex Agent extension for Pencode |
| [go](https://github.com/pencode-labs/go) | Go language server extension for Pencode, powered by gopls |
| [ui-demo](https://github.com/pencode-labs/ui-demo) | Pencode extension examples for actions, dialogs, menus, popups, and panels |
| [material-icons](https://github.com/pencode-labs/material-icons) | Material Design file icon theme extension for Pencode |
| [markdown-preview](https://github.com/pencode-labs/markdown-preview) | Read-only Markdown preview extension for Pencode with native source editing and split layout |

## Adding an extension

Open a PR that adds an entry to `extensions.json`, following the existing format.
